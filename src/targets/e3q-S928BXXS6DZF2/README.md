# e3q-S928BXXS6DZF2 target profile

This is the only native payload profile in this repository. It targets the
Galaxy S24 Ultra SM-S928B on firmware `S928BXXS6DZF2` and kernel
`6.1.145-android14-11-33419968-abS928BXXS6DZF2`.

The target header contains the S928B fingerprint, build tokens, logger string
offset, and P0 data. The exact device identity is in
[`docs/SM-S928B-S928BXXS6DZF2.md`](../../../docs/SM-S928B-S928BXXS6DZF2.md).
